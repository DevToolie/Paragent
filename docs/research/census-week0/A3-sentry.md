## Notes

1. **Nav tree implied by docs (not a full product sitemap scrape):** Org setup checklist drives Settings > Auth, Teams, Integrations, Projects/DSN; product surfaces include Issues, Alerts, Monitors (metric/cron/uptime), Discover, Dashboards, Releases, Stats, Spike Protection, Subscription, Developer Settings / Seer. Source: https://docs.sentry.io/organization/getting-started/ (2026-07-24) plus linked product docs above.

2. **Surprising for a “browser-agent cache” thesis:** Several high-value DevOps flows (GitHub App install, Slack OAuth, Jira Marketplace, SAML/SSO) are **explicitly multi-product browser consent wizards** in official docs — strong browser-only *candidates*. Meanwhile core CRUD (projects, alerts, monitors, tokens, filters, spike toggles) is heavily documented as console forms that A4 may find fully covered by REST — which would **weaken** Sentry as an anchor if those dominate frequency.

3. **Releases / source maps:** Official product docs emphasize SDK/CLI (`sentry-cli` sourcemaps upload, release notify) more than a multi-step console wizard for creating releases. Console still used for viewing Releases and resolving issues in a release (SN-11). Dedicated “upload source maps in UI” task **not** documented as a primary path in pages fetched — no claim of a UI upload wizard. Sources: https://docs.sentry.io/product/releases/ (2026-07-24); https://docs.sentry.io/platforms/javascript/sourcemaps/uploading/cli/ (2026-07-24).

4. **Performance / tracing:** Project Details docs point at processing/detector thresholds in Project Settings, but a crisp standalone “enable tracing” console wizard was not found as a distinct admin flow (tracing is primarily SDK config). No separate SN row invented for that. Source consulted: https://docs.sentry.io/product/projects/project-details/ (2026-07-24). Discover’s Transactions dataset is deprecated in favor of Trace Explorer per https://docs.sentry.io/product/discover-queries/ (2026-07-24).

5. **Slack install page:** Primary URL https://docs.sentry.io/integrations/notification-incidents/slack/ was fetched successfully via search index / prior retrieval on 2026-07-24; one direct WebFetch attempt timed out — steps cited match the official page content returned by search/docs snippets and org getting-started references.

6. **Absence discipline:** This file does **not** claim APIs/Terraform do or do not exist for any task (A4’s job). “No API found” statements intentionally omitted.

7. **Confidence:** Rows marked MED are those where end-state verification depends on billing UI copy or plan gating not fully walked end-to-end in this pass (SN-17, SN-24).
